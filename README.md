
# Data Analytics & Microsoft PL-300

This repository contains my learning, practice, and hands-on work in **Data Analytics using Microsoft Power BI**, with a focus on preparation for the **Microsoft Certified: Power BI Data Analyst (PL-300)** certification.

## Overview

The goal of this repository is to build practical skills in analyzing data, transforming raw datasets, creating semantic models, developing interactive reports, and generating meaningful business insights using Power BI.

## PL-300 Topics

### 1. Prepare the Data

* Connecting to different data sources
* Power Query
* Data profiling
* Data cleaning
* Handling missing and incorrect values
* Transforming data
* Merging and appending queries
* Data types
* Query parameters

### 2. Model the Data

* Semantic models
* Tables and columns
* Relationships
* Cardinality
* Star schema
* Date tables
* Calculated columns
* Measures
* DAX
* Storage modes
* Import
* DirectQuery
* Dual
* Partitioning
* Incremental refresh

### 3. Visualize and Analyze the Data

* Charts and tables
* Slicers
* Filters
* Drillthrough
* Tooltips
* Bookmarks
* Conditional formatting
* Interactive reports
* Data analysis
* KPIs
* Report design

### 4. Manage and Secure Power BI

* Power BI workspaces
* Semantic model management
* Data refresh
* Scheduled refresh
* Gateways
* Row-level security (RLS)
* Permissions
* Sharing and collaboration
